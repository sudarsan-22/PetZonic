# User Stories — Breeder

> **Role**: Verified Breeder  
> **Description**: Professional or hobby breeder with verified credentials and breeding history

---

## Onboarding & Verification

| ID | Story | Acceptance Criteria |
|----|-------|-------------------|
| US-BR01 | As a breeder, I want to register as a verified breeder so I get enhanced trust | Breeder role selection, additional verification flow triggered |
| US-BR02 | As a breeder, I want to upload my breeding license so I'm verified | License document upload (PDF/image), license number entry, issuing authority |
| US-BR03 | As a breeder, I want to upload facility photos so buyers see my setup | Min 3 facility photos, categories: kennel/cattery, play area, living area |
| US-BR04 | As a breeder, I want to specify breeds I work with so buyers find me | Select breeds from taxonomy, multiple breeds allowed, experience years per breed |
| US-BR05 | As a breeder, I want my verification badge displayed prominently so buyers trust me | "Verified Breeder" badge on all listings and profile, green checkmark icon |
| US-BR06 | As a breeder, I want to build a breeder profile page so buyers learn about me | Profile: about, experience, breeds, facility photos, breeding philosophy, reviews |

---

## Breeding Management

| ID | Story | Acceptance Criteria |
|----|-------|-------------------|
| US-BR07 | As a breeder, I want to manage my breeding dogs/cats (parent animals) | Parent animal registry: name, breed, age, health records, lineage |
| US-BR08 | As a breeder, I want to record litter information so I maintain history | Litter record: parents, date of birth, number of pups/kittens, photos |
| US-BR09 | As a breeder, I want to list a full litter at once so it's efficient | Litter listing: shared parent info, individual photos per puppy/kitten, gender/marking |
| US-BR10 | As a breeder, I want to show pedigree/lineage information so buyers know the bloodline | Family tree display (2-3 generations), parent photos, titles/certifications |
| US-BR11 | As a breeder, I want to track which pets from my breeding are sold | Sold history linked to litters, buyer info (for health follow-up), timeline |
| US-BR12 | As a breeder, I want to maintain health testing records for parent animals | Upload health certificates (hip score, eye test, DNA tests), display on profile |

---

## Listing & Sales

| ID | Story | Acceptance Criteria |
|----|-------|-------------------|
| US-BR13 | As a breeder, I want to create listings with enhanced details so buyers get full info | All standard listing fields + pedigree, parent photos, health guarantees, contract terms |
| US-BR14 | As a breeder, I want to set adoption criteria so I find responsible buyers | Buyer questionnaire: living situation, experience, yard, other pets, work hours |
| US-BR15 | As a breeder, I want to pre-screen buyer applications before confirming sale | Application queue: view buyer profiles, questionnaire answers, approve/decline |
| US-BR16 | As a breeder, I want to offer waiting lists for upcoming litters | "Join Waitlist" option on breeder profile/listings, notify when litter born |
| US-BR17 | As a breeder, I want to provide a health guarantee with my pets | Configurable guarantee period (30/60/90 days), terms displayed on listing |
| US-BR18 | As a breeder, I want to share post-sale care instructions with the buyer | Care guide attachment (PDF), feeding schedule, vet follow-up reminders |

---

## Communication & Reputation

| ID | Story | Acceptance Criteria |
|----|-------|-------------------|
| US-BR19 | As a breeder, I want to respond to inquiries about my breeds so I educate buyers | Chat with detailed breed info sharing, FAQ templates for common questions |
| US-BR20 | As a breeder, I want to see my reviews and rating so I can maintain reputation | Breeder rating displayed (aggregate), individual reviews visible, response option |
| US-BR21 | As a breeder, I want past buyers to post health follow-up reviews | Follow-up review prompt to buyers at 3/6 months, adds to breeder's health track record |
| US-BR22 | As a breeder, I want to showcase testimonials on my profile | Highlighted reviews section on breeder profile, pin best reviews |

## Analytics & Business

## Trust & Compliance

| ID | Story | Acceptance Criteria |
|----|-------|-------------------|
| US-BR26 | As a breeder, I want to update my license when it renews so my status stays active | License expiry tracking, renewal upload, notification before expiry |
| US-BR27 | As a breeder, I want my breeding frequency to be visible so buyers know I'm ethical | Litters per year displayed, max frequency guidelines shown, compliance badge |
| US-BR28 | As a breeder, I want to participate in platform-endorsed best practices | Best practices checklist, completion badge, highlighted in search |
